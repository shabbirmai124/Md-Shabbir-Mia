# 🖥️ Systems, Graphics & Low-Level Computing

### 🎮 The Unyielding Engine
**Repository:** `The-Unyielding-Engine`

A C++ graphics-engine workspace containing both a **CPU ray tracer** and a real-time **OpenGL-based rendering/physics engine**.

The engine work explores application loops, windowing, events, geometry processing, shader management, mathematics, physics hooks, timers, file utilities, and acceleration structures such as BVH components.

**Explores:** C++17 · OpenGL 4.6 · GLSL · CMake · GLFW · GLM · GLAD · ImGui

[Explore repository →](https://github.com/shabbirmai124/The-Unyielding-Engine)

### 🔐 Market Visit Problem
**Repository:** `Market_Visit_Problem`

A C concurrency problem used to model shared inventory across multiple activities using **processes, semaphores, and mutex locks**.

It demonstrates how synchronization primitives can be used to prevent conflicting concurrent access to a shared resource.

**Explores:** C · Processes · Semaphores · Mutexes · Concurrency

# 🧬 Experimental Computing

### Project Aeon — DNA Data Archive
**Repository:** `Project-Aeon-The-Immortal-Data-Protocol`

An experimental data-storage project exploring how digital data can be encoded into **DNA nucleotide sequences (A/C/G/T)** and later recovered after simulated corruption.

The system explores:

- Binary-to-DNA transcoding
- Reed-Solomon error correction
- Triple Modular Redundancy
- Mutation / radiation simulation
- Image-data encoding
- FASTA export
- Recovery after simulated errors

**Explores:** Python · Error Correction · Redundancy · Data Encoding · Experimental Storage

[Explore repository →](https://github.com/shabbirmai124/Project-Aeon-The-Immortal-Data-Protocol)
